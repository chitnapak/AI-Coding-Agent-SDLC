## Key Conventions

1. **camelCase API responses** — alias in SQL, never in TypeScript
2. **`migrate()` at module top-level** — never inside a handler
3. **DB changes touch 4 files** — `migrate.ts`, `seed.ts`, `helpers.ts`, `openapi.ts`
4. **`pageSize` capped at 100**, default 24
5. **Icons**: `lucide-react` only
6. **Run `npm run lint` before finishing** — zero errors required
7. **No pure black/white** in UI
